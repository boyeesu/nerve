# Support

ManClaw is an early open-source project maintained on a best-effort basis.

## Where to go

- **Usage question or idea:** start a GitHub Discussion when discussions are
  enabled.
- **Reproducible bug:** use the bug-report issue form.
- **Feature proposal:** use the feature-request issue form.
- **New runtime integration:** use the adapter-request issue form.
- **Security concern:** follow [SECURITY.md](SECURITY.md).
- **Community conduct concern:** follow
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Before opening an issue, search the repository and review the
[development guide](docs/DEVELOPMENT.md).

## What to include

Provide the ManClaw commit or version, browser and operating system, runtime
version when relevant, steps to reproduce, and sanitized logs or screenshots.
Never post tokens, private prompts, agent memory, or customer data.
